Module Map

Mobile casualty workflow

  • incidents provides the official incident picker.
  • casualties stores person-level identity/demographics.
  • casualty_incidents stores one casualty report within one incident.
  • casualty_triage_assessments stores system-calculated and responder triage data.

Admin dashboard

  • users stores admin, responder, and documenter accounts.
  • created_by ties responder/documenter accounts to their admin.
  • last_seen_at supports online/offline account display.
  • healthcare_facilities and evacuation_centers are admin-managed references.

Verification review

  • casualty_incidents.verification_status stores submitted, under review, verified, or rejected.
  • verified_by and verified_at store final approval metadata.
  • casualty_verification_history records each review action and notes.

SitRep/reporting

  • sitreps stores generated report payloads per incident.
  • Report payloads summarize casualties, triage, transport, facility use, and status.
  • incident_response_timelines and operations tables feed Utstein-style reporting.
